# 블록 터미널 캡처 (docs/10 §D5.8, 프리셋 11)

```powershell
foreach ($s in 'blocks','quiet','islands','mono','warm','access') {
  & tools/visual/capture.ps1 -Output crates/pod-app/qa/layouts/blocks -Scenes @('workspace') -Style $s -Layout block-terminal
}
```

fixture `workspace` 장면(데몬 없음, 100작업/300터미널), 보조 모니터 1440×960 physical @150%, 다크·라이트.
파일: `<dark|light>-workspace-<style>-block-terminal.png` + UIA 트리. 비교 대상: `docs/design/gallery/images/11-blocks-<dark|light>.png`.
모든 캡처를 목업과 나란히 놓고 직접 확인했다(2026-11-10). `native-qa.log`는 headless 키보드 흐름(`blocks_qa.rs`)의 단계 기록.

fixture에는 데몬이 없어 터미널 출력이 없다. 블록 터미널을 보일 때만 fixture 터미널 3개(task-000)에 Pod 셸 표시(OSC 133)가 든 출력을 넣고, 승인 요청 하나(`g-fixture`, 선택지 “이번만 허용/항상 허용”)를 작업 공간 gate 목록에 넣는다(`blocks.rs`의 `fixture_feed`/`fixture_gate`). 다른 레이아웃 캡처는 바뀌지 않는다.

## 목업과 같은 점

왼쪽 작업 목록(선택 강조, 승인 대기 수)과 에이전트 칩, 머리줄 `작업 제목 · 블록 N · 에이전트 M · 시간순 · 응답 필요 K`, 블록 머리(접기 표시 · 상태 아이콘 · `누구 · 이름` · 고정폭 명령 · 상태 · 복사), 끝난 이전 블록은 접힘·실행 중/승인 대기/마지막 블록은 펼침, 승인 대기 블록의 주황 테두리+왼쪽 띠, 블록 안 **이번만 허용 Y / 항상 허용 A / 거부 N**, 아래 입력 `…에게 입력 · Tab으로 대상 변경` + Enter 표시, diff 줄 색(`+` 녹색).

## 의도한 차이

- **이름이 `셸 · Worker N`**: fixture 터미널이 모두 powershell이다(에이전트면 `Claude · 구현`). 같은 이유로 에이전트 단계 블록(상태 전환)은 캡처에 없고 headless 테스트로 확인한다.
- **경과 시간(“42초째”) 대신 “실행 중”**, “방금” 대신 걸린 시간: 흐르는 시간을 그리려면 타이머가 필요하다(폴링 없음 규칙). 끝난 블록은 `3.1초 · 종료 0`.
- **블록 “…” 메뉴 대신 복사 단추**(C/Ctrl+C), 전체 화면 프로그램 블록에는 “전체 터미널로 보기”. 원본 터미널 전환은 머리줄 오른쪽 단추(목업의 패널 아이콘 자리), 필터 아이콘은 없다(칩이 필터).
- **선택된 블록 강조**(강조색 테두리+선택 면): 키보드 위치 표시. 목업에는 선택 표시가 없다.
- **승인 메시지**: gate의 `제목 · 메시지`를 경고색으로, 그 위에 블록 출력. 목업의 “명령 실행 승인이 필요합니다.”와 같은 자리.
- **제목줄**: 목업의 `pod / 작업명` 대신 앱 공용 제목줄(검색 · 설정). 상태줄도 작업 공간 공용.
- 작업 제목의 🔎 등 fixture 문자열은 fixture 그대로다.

## 스타일별

| 스타일 | 확인 |
|---|---|
| `blocks` (11) | 중립 다크/라이트, flat 블록(1px 경계), 주황 승인 대기 |
| `quiet` (04) | flat: 블록 1px 경계, 그림자 없음 |
| `islands` (08) | 블록이 반경 12 섬 + 그림자, 넓은 간격, 입력도 섬 |
| `mono` (09) | 경계 없음: 블록은 면, 보조 단추·선택 칩은 면(bg.hover/selected)으로 구분 |
| `warm` (10) | 웜 그레이 면, 녹 갈색 강조·선택 |
| `access` (14) | 2px 경계, UI 15px — 블록 머리·단추가 글자에 맞춰 커지고 잘리지 않음, 피드는 스크롤. **남은 문제**: 첫 화면은 피드 맨 위에서 시작한다(맨 아래 따라가기는 새 출력이 올 때 동작, fixture는 출력이 더 오지 않음) |
