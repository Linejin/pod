# 스타일 테마 캡처 (docs/10 §D5, THEMES 1단계)

`powershell -NoProfile -File tools/visual/capture-styles.ps1` — 내장 스타일 16개 × 다크/라이트, `workspace` 장면(fixture, 보조 모니터, 1440×960 physical @150%).
파일: `<dark|light>-workspace-<style>.png` + UIA 트리. 비교 대상: `docs/design/gallery/images/<NN>-*-<dark|light>.png`.
모든 캡처를 갤러리 목업과 나란히 놓고 직접 확인했다(2026-11-10).

## 공통 차이(모든 스타일)

- **장면이 다르다**: fixture `workspace`는 터미널이 열려 있지 않은 빈 dock + 100작업/300터미널이고, 목업은 터미널 4개가 열린 합성 장면이다. 색·면·밀도·행 구조를 비교하고 터미널 격자는 비교하지 않는다.
- **레이아웃 모드**: 이번 단계는 작업대만 있다. 02(집중 레일)·03/06(응답 대기열)·07(세부 열)·11(블록)·12(칸반)·13(리뷰 중심)은 같은 스타일 색으로 **작업대**에 그려지고, 설정에 “준비 중” 안내가 나온다.
- 제목줄: 목업의 로고 칩·breadcrumb·알림/패널 토글 아이콘은 아직 없다(검색 pill + 설정 아이콘만). sidebar 머리의 필터/더 보기 아이콘 대신 기존 다섯 동작(격자·작업·터미널·그룹·에이전트)을 아이콘으로 유지했다(접근성 이름 유지).
- 작업 행 오른쪽: 목업은 경과 시간(21분), 앱은 터미널 수 또는 응답/실패 배지. 경과 시간은 VM에 없다.
- 상태줄: 그룹·아이콘은 같지만 fixture라 연결 문구가 길다(`podd UI fixture (read only) · pid 0`).
